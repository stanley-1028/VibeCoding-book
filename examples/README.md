# 範例專案

本目錄收錄教材中可獨立執行的範例。每個範例都是一個最小但完整的作品，對應書中某個實戰單元。

| 範例 | 對應單元 | 說明 |
|---|---|---|
| [`text-tool/`](./text-tool/) | [入門實戰：做出一個可用的文字工具](../docs/first-project.md) | 命令列文字統計工具 `textstats`，含測試。 |

其餘單元（如中階的 `tasklite`）的完整程式碼已內嵌於對應單元的「核心內容」中，可依該單元步驟逐檔建立。

## 執行環境

範例以 Python 3.8 以上、僅使用標準函式庫為原則，不需額外安裝套件。
