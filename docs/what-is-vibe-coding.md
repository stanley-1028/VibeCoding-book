# 什麼是 Vibe Coding

> 用一句話說清楚：Vibe Coding 是用自然語言描述你想要的東西，讓 AI 產生程式碼，再由你負責執行、觀察與修正的開發方式。

## 學習目標

完成本單元後，你能夠：

1. 用自己的話說明 Vibe Coding 的定義與它和傳統手寫程式的差別。
2. 說出 Vibe Coding 的基本循環：描述 → 產生 → 執行 → 觀察 → 修正。
3. 在電腦上完成一次最小流程：請 AI 產生一段程式、實際執行、看懂輸出。

## 前置知識

- 本單元是入門路徑的起點，不需要任何程式背景。
- 你需要一台可以安裝與執行 Python 的電腦（安裝方式會在下一單元說明）。
- 需要一個可以輸入文字與 AI 對話的工具（例如網頁版聊天介面或編輯器內建的 AI 助理）。

## 為什麼重要

多數人想做的「小工具」其實不需要花幾個月學完整套程式設計。Vibe Coding 把「寫程式」的門檻，換成「把需求講清楚」的能力。它讓你用幾分鐘做出一個能跑的原型，先確認方向對不對，再決定要不要深入。當你知道這個循環怎麼運作，就不會把 AI 當成只會給答案的黑盒子，而是能反覆駕馭它的合作者。

## 核心內容

### 名詞的由來

「Vibe Coding」這個詞由 Andrej Karpathy 在 2025 年 2 月於社群平台上提出，用來描述一種開發風格：你完全交給感覺（vibe），用自然語言跟 AI 描述需求，接受它產生的程式碼，執行程式看結果，出錯就再把錯誤貼回去讓 AI 修。你不一定逐行讀懂每個字，但你要對「成品能不能用」負責。

需要分清楚兩種情況：

- **純 Vibe 模式**：適合一次性腳本、個人小工具、學習探索。錯了重來成本很低。
- **紀律模式**：適合會被別人使用、要長期維護、或牽涉金錢與個資的程式。此時你必須讀懂、測試、版控每一段程式碼。

本書會帶你從純 Vibe 起步，逐步補上紀律模式需要的技能。真正的專業能力，是知道什麼時候該用哪一種。

### 開發循環

Vibe Coding 不是「許願一次就結束」，而是一個可重複的循環：

```text
描述需求
   │
   ▼
AI 產生程式碼
   │
   ▼
你執行它  ──→ 觀察輸出/錯誤
   │                │
   └──── 把結果回饋給 AI ──┘
```

每一輪你都只做一件事：讓結果比上一輪更接近目標。一次改一點，比一次要求一個龐大系統容易成功。

### 最小範例：從一句話到能執行的程式

假設你說：

> 請用 Python 寫一個程式，讀取使用者輸入的一句話，算出有幾個字元（不含空白），並印出來。

AI 可能給你類似這樣的程式：

```python
# char_count.py
text = input("請輸入一句話：")
count = len([c for c in text if not c.isspace()])
print(f"不含空白的字元數：{count}")
```

執行方式（在終端機輸入）：

```text
python char_count.py
```

輸入與預期輸出：

```text
請輸入一句話：今天天氣很好
不含空白的字元數：6
```

你不需要一開始就懂 `[... for c in text ...]` 這種寫法。但你要做的是：**真的執行它**，看輸出對不對，再想想有沒有邊角情況。例如全形空格 `　`（U+3000）算不算空白？這類問題就是下一輪要追問 AI 的內容。

### 你負責的三件事

AI 能寫程式，但它不知道你的真實環境與意圖。以下三件事永遠是你的責任：

1. **執行與觀察**：AI 無法替你按執行鍵，也看不到你螢幕上的真實錯誤。
2. **判斷對錯**：輸出符合你的期待嗎？有沒有更簡單的做法？
3. **安全與界線**：不要讓 AI 產生或處理你不該外洩的密碼、金鑰、個資。

## 常見坑

| 錯誤 | 原因 | 正確做法 |
|---|---|---|
| 一次要求一個超大系統 | 需求太模糊，AI 只能猜 | 拆成小步驟，一次只做一個能執行的功能 |
| 沒執行就直接相信程式碼 | 以為 AI 一定對 | 每輪都執行，用輸出驗證，而不是用「看起來對」判斷 |
| 出錯就把整段重寫 | 不知道錯在哪 | 把完整錯誤訊息貼回給 AI，請它解釋並提出最小修正 |
| 把密碼或金鑰貼進對話 | 分不清哪些資料敏感 | 一律用假資料或環境變數，真實機密永不貼出 |
| 沒有備份就想大改 | 改壞了回不去 | 動手前先把檔名存成 `xxx_v1.py`，或使用版本控制 |

## 動手練

**練習**：用你慣用的 AI 對話工具，請它「用 Python 寫一個程式，讀取兩個整數，印出它們的和與乘積」，把程式存成 `calc.py` 並實際執行。執行成功後，再做一次修改：請 AI 處理「使用者輸入的不是整數」的情況，並重新測試輸入 `abc` 會發生什麼。

**提示**：若執行時出現 `python: command not found`，代表環境還沒裝好，先跳到下一單元。若 AI 的程式用到你沒聽過的函式，直接問它「這一行在做什麼，請用一句話解釋」。
