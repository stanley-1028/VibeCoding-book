# 提示詞入門：把話說清楚

> 學會把「我想要什麼」拆成 AI 能準確執行的指令：說明目標、輸入、輸出、限制與範例。

## 學習目標

完成本單元後，你能夠：

1. 運用「目標、輸入、輸出、限制、範例」五要素寫出清楚的提示詞。
2. 針對同一個需求，改寫模糊提示詞使其可執行且可驗證。
3. 用「請先反問我」的方式，讓 AI 在動手前釐清缺口。

## 前置知識

- 先完成 [準備你的 AI 開發環境](./setup-ai-environment.md)。
- 你能在終端機執行 `.py` 檔並讀懂基本輸出。

## 為什麼重要

同一個 AI，對「幫我做個記帳程式」和對「寫一個 Python 函式，輸入一串金額，回傳總和與平均，不處理負數並印出警告」給出的結果品質差距極大。提示詞不是話術，而是**把規格傳達出去**的手段。提示詞寫得準，你就少改三輪；寫得含糊，AI 只能猜，而猜錯的成本由你承擔。

## 核心內容

### 五要素框架

一個可執行的提示詞，通常包含這五個部分：

| 要素 | 回答的問題 | 例子 |
|---|---|---|
| 目標 | 要做什麼？ | 讀取文字檔並統計字數 |
| 輸入 | 資料從哪來、長什麼樣？ | 檔名由命令列參數傳入，UTF-8 純文字 |
| 輸出 | 結果長什麼樣、印到哪？ | 在終端機印出「總字數：N」 |
| 限制 | 用什麼寫、不能用什麼？ | 只用 Python 標準函式庫，不裝套件 |
| 範例 | 有沒有具體樣本？ | 輸入 `hello world` 應輸出 `總字數：11` |

不是每個提示詞都要湊滿五項，但當結果不如預期時，回頭檢查通常是少了其中某一項。

### 從模糊到精確

**模糊版本**：

> 幫我寫一個算成績的程式。

AI 會問你或自己假設：幾分及格？成績怎麼輸入？要平均嗎？以下是一個精確版本：

> 請用 Python 標準函式庫寫一個程式 `score.py`。
> 目標：讀取使用者依序輸入的整數成績，直到輸入 `done` 為止。
> 輸出：印出「平均：X.X」與「及格人數：N」，及格分數為 60。
> 限制：全部成績輸入結束後才輸出；若一筆成績都沒有，印出「沒有成績」。
> 範例：輸入 `80`、`50`、`60`、`done` 應輸出「平均：63.3」與「及格人數：2」。

對應的參考程式：

```python
# score.py
scores = []
while True:
    raw = input("請輸入成績（輸入 done 結束）：")
    if raw == "done":
        break
    scores.append(int(raw))

if not scores:
    print("沒有成績")
else:
    passed = len([s for s in scores if s >= 60])
    print(f"平均：{sum(scores) / len(scores):.1f}")
    print(f"及格人數：{passed}")
```

預期輸出：

```text
請輸入成績（輸入 done 結束）：80
請輸入成績（輸入 done 結束）：50
請輸入成績（輸入 done 結束）：60
請輸入成績（輸入 done 結束）：done
平均：63.3
及格人數：2
```

### 讓 AI 先反問

當你也不確定需求時，最有效的提示詞是：

> 我想做一個每天提醒我喝水的小程式。請先不要寫程式，先問我 5 個你需要知道才能動手的問題。

這會逼迫 AI 把隱含假設攤開，讓你用一輪問答補齊規格，而不是收到一個猜錯方向的成品。

### 迭代提示詞的句型

- 縮小範圍：「只改 `main` 函式，不要動其他部分。」
- 要求解釋：「先解釋你打算怎麼做，我同意後再寫。」
- 指定形式：「用一個函式完成，不要用類別。」
- 提供回饋：「輸出是 `平均：63.33`，我要小數一位，請修正。」
- 要求取捨：「給我兩個做法，並各用一句話說明優缺點。」

## 常見坑

| 錯誤 | 原因 | 正確做法 |
|---|---|---|
| 一次塞五個需求 | 注意力被分散，容易漏做 | 一次一個需求，確認後再下一個 |
| 只說「幫我優化」 | 「優化」沒有標準 | 說清楚優化什麼：速度、可讀性、還是行數 |
| 沒有給範例 | AI 不知輸出格式 | 提供一組輸入與預期輸出 |
| 出錯就換一個新提示 | 沒把錯誤回饋進去 | 保留原對話，貼上錯誤與現況再要求修正 |
| 假設 AI 記得前文細節 | 對話太長時細節被沖淡 | 重要限制在每次提示中重申 |

## 動手練

**練習**：針對「把一句英文轉成全大寫並計算母音數量」這個需求，先寫一個模糊提示詞，觀察 AI 的產出；再用五要素框架改寫，要求只用標準函式庫並附範例。實際執行兩個版本，比較差異。最後，用「請先反問我 5 個問題」的句型，為你心中另一個小工具收集規格。

**提示**：母音定義要先講清楚（a、e、i、o、u，是否區分大小寫）。若 AI 的輸出格式跟你的範例不同，直接說「輸出應與範例完全一致」。

## 完成檢核標準

- [ ] 我能列出五要素並各舉一例。
- [ ] 我寫出的提示詞包含至少三個要素，且 AI 一次就產出可執行結果。
- [ ] 我實際比較過模糊與精確提示詞的輸出差異。
- [ ] 我用過「請先反問我」句型，並收到具體問題清單。
- [ ] 我能在需求變更時，用迭代句型請 AI 做最小修改。
